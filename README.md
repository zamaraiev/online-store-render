# Online store (Lab 3, task 3.4.3)

Node.js (Express) web application on Render that reads the cost of purchases from an
Azure SQL database. Variant 5, "Online store". The tables are created by the task 3.2
scripts; the logical model is in `docs/logical_model.png`.

Render settings: runtime Node, build command `npm install`, start command `npm start`.

Environment variables: `DB_SERVER`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`.
